# Works with Ofox

A curated list of apps and tools built with [Ofox](https://ofox.ai). Ofox is a unified gateway — one API key to reach Claude, GPT, Gemini, DeepSeek and more.

## What is Ofox?

[Ofox](https://ofox.ai) gives you a single interface to AI models across providers, through one API.

**Why Ofox:**
- One interface to many AI models
- Automatic fallback and load balancing
- No vendor lock-in

## Get an API key

1. Sign up at [ofox.ai](https://ofox.ai)
2. Add credits and generate an API key in the dashboard
3. Use it in any app below, or integrate it into your own project
